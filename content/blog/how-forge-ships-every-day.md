Forge grows with a **daily implementation calendar**.

Foundation phases F00–F11 create a hostable shell. Tool phases P001+ add real utilities. Hub and SEO days keep topical authority honest.

## Rules that keep Google (and users) happy

1. Sitemap includes **shipped** tools only
2. Planned tools may exist as **noindex** coming-soon pages
3. Never open a category with empty fake widgets
4. `main` always deploys

When JSON Formatter ships in P001, it will replace the planned placeholder — same URL, real engine.
