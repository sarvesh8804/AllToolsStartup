The first interactive tools on Forge are the JSON pair:

- **JSON Formatter** — beautify / pretty-print
- **JSON Validator** — catch syntax errors early

Both will process text in your browser. You can already preview their coming-soon pages under Tools.

If you care about a privacy-friendly alternative to classic JSON utilities, this is the beachhead.
